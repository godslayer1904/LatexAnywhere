∑ LatexAnywhere Help

Type math in any text box, the Obsidian + Latex Suite way.

Basics

  1. In any text box (chat apps, Word, browsers, Notepad…) press Alt+L; the formula box pops up next to the cursor.
  2. Type your formula. The box runs the original Latex Suite: x^2 becomes x^{2}, // makes a fraction, Tab jumps to the next placeholder.
  3. The rendered formula is shown live above.
  4. Insert it with any of the keys below; it lands where your cursor was.

Select text first and press Alt+L to edit it; inserting replaces the selection.

Insert

KeyInsertsFor
Enterthe formula x^{2}LaTeX sources, Overleaf
Alt+Enterinline math with $: $x^{2}$Typora, Obsidian, Markdown

Ctrl+Shift+Entera native Word equation (editable)Word, PowerPoint
Shift+Entera new line in the boxmulti-line formulas

Input methods

  • 进框时自动切成英文，打公式不用手动切Input methods；框里要打中文时按 Shift 切换。
  • Back in your text box, the IME returns to its previous language.

The box

  • It grows with its content and wraps long lines.
  • Drag it by any area outside the text.
  • Follows the system dark / light theme.

Tray and safety

  • It runs in the system tray (purple ∑ icon). Right-click to toggle Start with Windows or Quit.
  • Emergency quit: Win+Alt+L, works even if the tray does not respond.
  • It watches its own memory and CPU and restarts itself if anything goes wrong; a crash recovers within a second.
